# 🚀 تكنو-فجن | Techno-Vision

مشروع صفحة هبوط (Landing Page) عصرية ومتجاوبة مخصصة لشركات البرمجيات وحلول التحول الرقمي، تم تصميمها وبرمجتها بأحدث التقنيات لتقديم تجربة مستخدم سلسة واحترافية.

---

## 🌟 المميزات الرئيسية

- **دعم اللغتين (عربي / إنجليزي):** إمكانية تبديل لغة الموقع بالكامل بضغطة زر واحدة مع تأثير انتقال ناعم (Fade Effect).
- **الوضع الليلي والنهاري (Dark / Light Mode):** دعم التبديل بين الثيمات مع حفظ تفضيلات المستخدم تلقائياً باستخدام `localStorage`.
- **تصميم متجاوب (Fully Responsive):** يتناسب تماماً مع كافة الشاشات والأجهزة الذكية (الهواتف، الأجهزة اللوحية، أجهزة سطح المكتب).
- **تأثيرات بصرية جذابة:** استخدام الرسوم المتحركة (CSS Animations) وتدرجات الألوان الديناميكية لإضفاء طابع احترافي.
- **نموذج تواصل تفاعلي:** نموذج إرسال رسائل واستفسارات يدعم التحقق من المدخلات وإظهار حالة الإرسال.

---

## 🛠️ التقنيات المستخدمة

تم بناء المشروع باستخدام التقنيات الأساسية للويب دون الاعتماد على مكتبات خارجية ضخمة لضمان السرعة والأداء العالي:

- **HTML5:** لهيكلة وتصميم صفحات الويب بشكل قياسي ودلالي.
- **CSS3:** لتنسيق التصميم بالكامل، دعم المتغيرات (`CSS Variables`)، وتطبيق الوضع المظلم.
- **JavaScript (ES6+):** للتحكم التفاعلي (تبديل اللغات، إدارة الثيمات، وإدارة نموذج التواصل).
- **Google Fonts:** استخدام خط **Cairo** العربي لضمان وضوح وجمالية النصوص.
